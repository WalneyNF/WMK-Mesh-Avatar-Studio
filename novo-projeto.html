Crie a pasta e os arquivos iniciais do seu personagem sem usar o terminal. O projeto da Miko será preservado.

1. Dados do personagem

Use letras sem acentos, números, hífen ou sublinhado.

Prefira imagem frontal, com fundo transparente, pelo menos 800 px de altura e boca e olhos visíveis.

Destino: projects/<nome>/, dentro da instalação WMK.

2. Pré-visualização

Escolha uma imagem para visualizar.

3. Resultado

Aguardando dados do novo personagem.

O que é criado?

O assistente usa o gerador original do projeto para criar source.png, avatar.json, rig.draft.json e a pasta work/.

Importante: este é um rascunho inicial. O sistema ainda não detecta automaticamente os olhos nem cria todas as camadas. A abertura completa no editor depende dessas etapas. Não tente reutilizar o rig da Miko em outra imagem.

Próxima evolução: detectar landmarks com IA, corrigir pontos em uma tela visual e construir as camadas automaticamente.
