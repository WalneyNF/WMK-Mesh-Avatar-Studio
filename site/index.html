Crie no Studio

Da sua ilustração para um arquivo de avatar.

Um agente de código prepara a estrutura e as camadas. Você revisa o resultado e ajusta as partes em um editor local.

  1. 01

    Dê uma ilustração ao seu agente

    Abra o Claude Code ou o Codex no repositório e peça para ele seguir o guia do agente. Um PNG de frente com fundo transparente funciona melhor.

  2. 02

    Revise o movimento

    Abra o projeto no Studio. Use Teste de pose para virar a cabeça e fechar os olhos, depois escolha um estilo de boca em Sincronia labial. Abra Ajustes finos para ajustar ou testar um arquivo de áudio.

  3. 03

    Ajuste arrastando as alças

    Selecione uma parte e mova seus pontos na imagem. A prévia acompanha suas edições. Se um contorno mudar as camadas de corte, escolha Salvar e reconstruir camadas.

  4. 04

    Adicione variantes desenhadas para expressões mais ricas

    Solicite olhos e bocas desenhados em Variantes desenhadas para dar mais personalidade a piscadas, sincronia labial e sorrisos. Quando estiver bom, escolha Exportar .mavatar para empacotar a estrutura, as camadas construídas e os desenhos em um único arquivo.

Comece localmente com npm install e npm run dev. Siga o guia de instalação ↗

Use ao vivo

Mova com seu rosto. Leve para sua live.

A página Live do Studio envia o movimento do seu avatar para uma visualização de stream separada que você pode adicionar ao OBS.

Rastreie seu rosto ou use sua voz

Inicie a câmera e calibre, depois ajuste espelhamento, sensibilidade e suavização. A câmera é opcional: a sincronia labial por microfone pode comandar a boca enquanto o movimento de repouso continua.

Adicione uma Browser Source no OBS

Escolha um fundo, copie a URL do OBS e adicione como Browser Source. Use transparência no OBS ou um fundo verde para chroma key em outros softwares de captura.

Ambas as visualizações usam o servidor de desenvolvimento local. Mantenha a página Live aberta em sua própria janela enquanto transmite. Sem nenhuma configuração, o Player move um arquivo .mavatar com sua câmera e microfone no navegador, para Captura de Janela no OBS. Guia de streaming ↗

Integrar com mesh-avatar

Um avatar no canvas do seu aplicativo.

Carregue o arquivo que você exportou do Studio. O runtime começa a animá-lo, e seu aplicativo controla sua pose, expressões e nível de voz.

  • WebGL
  • Módulos ES
  • Tipos TypeScript
  • Sem dependência de React

Instale o runtime

npm install mesh-avatar

Coloque seu arquivo .mavatar nos assets públicos do seu aplicativo. Adicione o canvas ao seu HTML e execute o JavaScript a partir da entrada de módulo do seu aplicativo.

O movimento de repouso e o piscar começam automaticamente. Para fala, seu aplicativo reproduz o áudio e envia seu volume para o runtime.

API do runtime e exemplos ↗

Adicione um canvas HTML

<canvas id="avatar" width="720" height="960"></canvas>

Carregar e controlar JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(
  canvas, '/avatars/character.mavatar'
);

// Escolha uma expressão ou defina uma pose.
avatar.setExpression('smile');
avatar.setParameters({ angleX: 10, gazeX: 0.25 });

// Enquanto seu app reproduz áudio, envie seu volume (0–1).
avatar.setSpeaking(true);
avatar.setVoiceLevel(0.6);

// Quando a fala terminar, retorne ao repouso.
avatar.setVoiceLevel(0);
avatar.setSpeaking(false);
avatar.setExpression('neutral');
avatar.setParameters({});

// Chame avatar.destroy() ao remover o canvas.

Como esta prévia funciona JavaScript

import { loadMeshAvatar } from 'mesh-avatar';

const canvas = document.querySelector('#avatar');
const avatar = await loadMeshAvatar(canvas, 'miko.mavatar', { padTop: -0.04 });

// Botões de expressão mudam o rosto.
for (const button of document.querySelectorAll('[data-expression]')) {
  button.addEventListener('click', () => {
    avatar.setExpression(button.dataset.expression);
  });
}

// Falar alterna a fala; esta demonstração envia uma curva de volume silenciosa em vez de áudio.
let speaking = false;
document.querySelector('#talk').addEventListener('click', () => {
  speaking = !speaking;
  avatar.setSpeaking(speaking);
  if (!speaking) avatar.setVoiceLevel(0);
});

// Vire a cabeça e os olhos em direção ao ponteiro (x e y vão de -1 a 1).
const hero = document.querySelector('.hero');
hero.addEventListener('pointermove', (event) => {
  const rect = hero.getBoundingClientRect();
  const x = (event.clientX - rect.left) / rect.width * 2 - 1;
  const y = 1 - (event.clientY - rect.top) / rect.height * 2;
  avatar.setParameters({ angleX: x * 12, angleY: y * 8, gazeX: x * 0.7, gazeY: y * 0.55 });
});
hero.addEventListener('pointerleave', () => avatar.setParameters({}));

// Enquanto fala, envie um valor de volume (0–1) a cada quadro.
function frame(time) {
  if (speaking) avatar.setVoiceLevel(Math.abs(Math.sin(time / 90)));
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
