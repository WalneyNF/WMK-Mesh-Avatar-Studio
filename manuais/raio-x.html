Resumo

O projeto transforma ilustrações preparadas em avatares 2D deformáveis. Não é um gerador automático universal de rig e não produz um modelo 3D. A interface separa árvore de partes, edição geométrica e prévia.

Arquitetura e riscos

Editor React/TypeScript; construtor Python/uv; runtime de malha; Live com MediaPipe; API local para projetos e arquivos .mavatar. Riscos: permissões de arquivos, máscaras inconsistentes, renderização de malhas densas, estabilidade da webcam e strings dispersas.

Roadmap sugerido

  1. Concluir PT-BR em editor, Live e workflows; revisar textos longos.
  2. Integrar logo WMK nos cabeçalhos, favicon e páginas secundárias.
  3. Validar contraste, navegação por teclado e layouts pequenos.
  4. Resolver ambiente de testes de symlinks no Windows sem afrouxar segurança.
  5. Automatizar testes de export/import e regressão visual.
  6. Publicar exemplos de integração runtime com jogos HTML/JS.
  7. Medir FPS e consumo de memória por complexidade de malha.

Este relatório é um diagnóstico técnico inicial, não uma auditoria completa.
