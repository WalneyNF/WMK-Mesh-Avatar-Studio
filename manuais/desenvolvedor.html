1. Instalação e testes

cd /d C:\ferramentas\mesh-avatar-studio
npm ci
npm run doctor
npm run dev
npm run build
npm test
npm run lint

Stack: React 19, TypeScript, Vite 7, MediaPipe Tasks Vision; Python 3.10+ e uv para gerar camadas. Playwright Chromium é opcional para editor básico, mas necessário para revisão automatizada.

3. Fluxo de dados

source.png + rig.draft.json
   ↓ Python + uv (build-layers)
rig.json + built/layers.json + PNGs
   ↓ validação e carregamento
Editor React → Runtime de malha → Preview / Live / OBS

4. Construção manual

uv run --with numpy --with pillow --with opencv-python-headless tools/build-layers.py projects/meu-avatar --rig rig.draft.json

O processo pode substituir camadas geradas. Faça backup. O projeto de exemplo não fornece coordenadas universais.

5. Internacionalização

Inclua chaves em src/editor/i18n.tsx e nos dicionários específicos do Live/workflow. Preserve fallback inglês e tipagem TypeScript. Teste editor, Live, exportação e erros.

6. Segurança

Não exponha o servidor de desenvolvimento à internet. Valide caminhos de arquivos e proteja contra traversal e symlinks; trate .mavatar como entrada não confiável. Webcam/microfone exigem consentimento. Não publique tokens nem imagens privadas.

7. Desempenho

Malhas densas aumentam custo de CPU/GPU; meça FPS, latência de tracking, uso de memória e tempo de reconstrução. Evite processamento de máscara a cada quadro.

8. Exercícios

  1. Adicionar uma tradução e testar fallback.
  2. Validar um campo de rig fora dos limites.
  3. Testar round-trip .mavatar.
  4. Medir FPS com e sem iluminação.
